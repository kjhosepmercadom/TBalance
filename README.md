# TBalance — Sistema de Inventario

Proyecto de aula de **Programación de Computadores III** (Universidad Popular del Cesar).

Este repositorio parte del código del *Sistema de Inventario TBalance* desarrollado en Programación II (Java 17, JavaFX con WebView y persistencia en archivos JSON). Durante P3 el equipo reestructura su arquitectura aplicando patrones GRASP, principios SOLID y Código Limpio.
